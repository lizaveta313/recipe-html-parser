# Описание проекта

## Тема

Разработка и тестирование синтаксического анализатора для обработки HTML-страниц.

## Цель

Создать учебное приложение, которое анализирует HTML-страницы рецептов сайта `eda.rambler.ru`, извлекает данные рецепта и показывает отчет о найденных данных и ошибках разметки.

## Задачи

- реализовать токенизацию HTML;
- построить простое DOM-дерево;
- извлечь данные рецепта;
- найти ошибки и предупреждения;
- сохранить отчет в базу данных;
- сделать веб-интерфейс для анализа и просмотра истории;
- написать тесты для parser engine и API.

## Описание проекта

Recipe HTML Parser принимает URL рецепта или HTML-код. Backend запускает parser engine, который разбирает HTML на токены, строит внутреннее DOM-дерево, извлекает рецепт и считает метрики страницы.

Из рецепта извлекаются название, ингредиенты, шаги приготовления, время, изображение, автор, категория, теги и пищевая ценность, если они есть в HTML.

## Алгоритм работы

1. Пользователь вводит URL или HTML.
2. Backend проверяет входные данные.
3. Для URL backend загружает HTML страницы.
4. Tokenizer разбивает HTML на токены.
5. DOM parser строит дерево узлов.
6. Recipe extractor ищет данные рецепта.
7. HTML analyzer формирует ошибки, предупреждения и метрики.
8. Отчет сохраняется в базу данных.
9. Frontend показывает результат пользователю.

## Архитектура

Проект состоит из трех основных частей:

- `backend` — FastAPI-приложение, API, сервисы, база данных;
- `frontend` — Next.js-интерфейс;
- `parser_engine` — учебный модуль синтаксического анализа HTML.

Для локального запуска используется SQLite. В Docker вместе с проектом поднимается PostgreSQL.

## Тестирование

Backend-тесты проверяют tokenizer, DOM parser, extractor, analyzer и API endpoints. Для тестов используются локальные HTML fixtures, поэтому реальные запросы к сайту не нужны.

Команды:

```bash
cd backend
pytest
pytest --cov=app --cov-report=term-missing
```

## Заключение

В проекте реализован полный учебный цикл обработки HTML-страницы: от токенизации и построения DOM до извлечения данных рецепта, сохранения отчета и проверки работы тестами.
